1. Étape 1

    Appliquer Fabulous Hair Serum des racines vers les pointes. Pour un soin complet, 3 pipettes sont nécessaires : sur le cuir chevelu, les longueurs et les pointes.

  2. Étape 2

    Laver les cheveux avec un shampoing classique. Pour un résultat optimal, utiliser le soin 3 fois par semaine.

  • Ne pas utiliser le soin les 2 jours qui précèdent et qui suivent une coloration.
  • Éviter tout contact avec les yeux.
  • Usage externe uniquement.
