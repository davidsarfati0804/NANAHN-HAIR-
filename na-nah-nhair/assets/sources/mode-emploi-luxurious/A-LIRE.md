# Mode d'emploi Luxurious – intégration

Même principe que pour Miraculous et Fabulous. Fiche produit Luxurious : remplacer le contenu du bloc « Mode d'emploi » (l'encadré « À COMPLÉTER ») par le contenu de `mode-emploi-luxurious.html`. Garder le titre « Mode d'emploi » et le cadre existants.

1. Copier le dossier `images/mode-emploi-luxurious/` dans le dossier d'images du site (illustrations en rose foncé, ton sur ton ; adapter les chemins `src` si besoin).
2. `mode-emploi.css` : version finale pour les trois soins (couleurs Miraculous, Fabulous et Luxurious). Remplacer l'ancienne version par celle-ci.
3. Fond des encadrés : rose pâle du flacon Luxurious (valeur provisoire `#F8DDE6`, à aligner sur celle du site), texte rose foncé `#7A2E4C`.
4. Tester les trois fiches produits sur mobile et sur ordinateur.
