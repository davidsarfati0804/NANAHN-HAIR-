# Mode d'emploi Fabulous – intégration

Même principe que pour Miraculous. Fiche produit Fabulous : remplacer le contenu du bloc « Mode d'emploi » (l'encadré « À COMPLÉTER ») par le contenu de `mode-emploi-fabulous.html`. Garder le titre « Mode d'emploi » et le cadre existants.

1. Copier le dossier `images/mode-emploi-fabulous/` dans le dossier d'images du site (illustrations en vert foncé, ton sur ton ; adapter les chemins `src` si besoin).
2. Le CSS `mode-emploi.css` est le même que pour Miraculous (avec en plus la couleur de texte verte pour Fabulous) : le remplacer par cette version, une seule feuille de styles pour les trois soins.
3. Fond des encadrés : vert menthe du flacon Fabulous (valeur provisoire `#DDF1E6`, à aligner sur celle du site), texte vert foncé `#1F5A43`.
4. Tester sur mobile et sur ordinateur.
